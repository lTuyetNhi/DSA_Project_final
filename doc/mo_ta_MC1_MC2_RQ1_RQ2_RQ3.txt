MO TA CHUC NANG DU AN HE THONG QUAN LY THU VIEN
===================================================

TONG QUAN
Du an gom 5 chuc nang DSA:
MC1: Tra cuu tai lieu theo ma.
MC2: Tim tai lieu co so luot muon cao nhat.
RQ1: Tra cuu tai lieu theo the loai.
RQ2: Theo doi tai lieu dang muon va qua han.
RQ3: Quan ly danh sach cho muon theo FIFO.

MC1 - TRA CUU CHINH XAC TAI LIEU THEO MA
Dinh nghia: Nguoi dung nhap book_id duy nhat, he thong tra ve dung tai lieu.
Input: book_id.
Output: Thong tin Book hoac Book not found.
Access pattern: Exact-key lookup.
Data: books.json, truong book_id.
Baseline: Linear Search, O(n).
Final solution: Hash Table, search trung binh O(1).
Edge cases: ma khong ton tai, input rong, dataset rong, book_id trung.

MC2 - TIM TAI LIEU DUOC MUON NHIEU NHAT
Dinh nghia: Tim Book co borrow_count cao nhat va cap nhat khi co luot muon moi.
Input: Khong bat buoc tham so tim kiem.
Output: book_id, title, borrow_count.
Access pattern: Extreme / Priority Query.
Data: books.json, truong book_id va borrow_count.
Baseline: Linear Scan tim max, O(n).
Final solution: Max-Heap; getMax O(1), insert/update O(log n).
Tie-break de xuat: borrow_count bang nhau thi book_id nho hon duoc uu tien.
Edge cases: dataset rong, mot sach, nhieu sach cung max, borrow_count thay doi.

RQ1 - TRA CUU TAI LIEU THEO THE LOAI
Dinh nghia: Nhap category va tra ve tat ca sach thuoc category do.
Input: category.
Output: Danh sach Book.
Access pattern: Equality Multi-result Lookup.
Data: books.json, truong category va book_id.
Baseline: Linear Scan, O(n).
Final solution: Hash Table category -> List<BookID>.
Do phuc tap truy van: O(1 + k) trung binh, k la so sach tra ve.
Edge cases: category khong ton tai, khong co sach, rat nhieu sach, sach doi category.

RQ2 - THEO DOI TAI LIEU DANG MUON VA QUA HAN
Dinh nghia: Theo doi phieu muon dang hoat dong va tim cac phieu vuot han tra.
Dieu kien qua han: status == BORROWING va due_date < current_date.
Input: current_date.
Output: Danh sach BorrowRecord dang muon/qua han.
Access pattern: Range Query theo due_date.
Data: borrow_records.json.
Cac truong chinh: borrow_id, reader_id, book_id, borrow_date, due_date, return_date, status.
Baseline: Linear Scan, O(n).
Final solution: Balanced BST theo due_date.
Insert: O(log n). Range Query: O(log n + k).
Neu nhieu phieu cung due_date: mot node luu List<BorrowRecord>.
Khong can luu OVERDUE co dinh; co the tinh dong.
Edge cases: khong co qua han, dataset rong, trung due_date, phieu RETURNED, tat ca qua han.

RQ3 - DANH SACH CHO MUON FIFO
Dinh nghia: Khi sach het, doc gia vao hang cho; ai dang ky truoc duoc phuc vu truoc.
Input: book_id, reader_id, registered_at.
Output: Danh sach cho hoac doc gia tiep theo duoc muon.
Access pattern: FIFO - First In, First Out.
Data: waitlist.json.
Cac truong: wait_id, book_id, reader_id, registered_at.
Baseline: Array/List; xoa dau co the O(n).
Final solution: Queue FIFO tu cai dat.
enqueue O(1), dequeue O(1), peek/front O(1).
To chuc runtime de xuat: Hash<BookID, Queue>, moi sach co Queue rieng.
Khong can priority, rank hay position.
Edge cases: queue rong, mot nguoi cho, nhieu nguoi cho, nhieu sach co waitlist.

BANG TOM TAT
MC1 | Exact Lookup | Linear Search O(n) | Hash Table O(1) average
MC2 | Extreme/Priority | Linear Scan O(n) | Max-Heap: max O(1), update O(log n)
RQ1 | Multi-result Equality | Linear Scan O(n) | Category Hash O(1+k) average
RQ2 | Range Query | Linear Scan O(n) | Balanced BST O(log n+k)
RQ3 | FIFO | Array/List, dequeue O(n) | Queue, enqueue/dequeue O(1)

MAPPING DATA -> DSA
books.json:
- book_id -> Hash Table -> MC1
- borrow_count -> Max-Heap -> MC2
- category -> Category Hash -> RQ1

borrow_records.json:
- due_date -> Balanced BST -> RQ2

waitlist.json:
- book_id -> Hash<BookID, Queue>
- registered_at -> thu tu FIFO -> RQ3
